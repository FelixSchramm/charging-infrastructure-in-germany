## Known pitfalls

- Session lineage is capped at depth 8: a session at depth 8 cannot
  `create_session` or create triggers. The chain then needs a fresh start by
  the user or the fallback routine.

- The proxy blocks `DELETE` on git refs, so the remote branch
  `issue-32-shared-data-prep` could not be deleted; the user can delete it.
  Same for `issue-30-streamlit-ui-fixes` (2026-10-10: "Write access to this
  GitHub API path is not permitted through this proxy.", HTTP 403).
  Same for `issue-34-dash`, `issue-35-shiny`, `issue-39-solara`,
  `issue-38-nicegui`, `issue-37-reflex`, `issue-42-quarto`, `issue-40-observable`, `issue-41-evidence` and `issue-43-react` (git push
  --delete: "remote end hung up" / no effect).
- Dash prototype: `AppShellHeader` has a fixed height; it is set per
  breakpoint (`{"base": 124, "sm": 88}`) so the wrapped title fits at 390 px.
  Stacked Plotly bars list the legend reversed unless `traceorder="normal"`.
- Headless Chromium works for screenshots:
  `uv run --no-project --with playwright python shot.py` with
  `executable_path="/opt/pw-browsers/chromium"`.
- `pkill -f "streamlit run"` inside a compound Bash command kills the shell
  itself (pattern matches the command line); run it as a separate call.
- Auto mode blocks reviewer merges via `gh api -X PUT .../pulls/N/merge`
  ("Merge Without Review"). The github MCP tool `merge_pull_request` (after
  posting the review) worked for PR #47. If a merge is blocked, do not work
  around it: record "merge pending" here and ask the user to merge on GitHub.

- Shiny Express renders every top-level string into the page, including a
  module docstring; use a comment header instead. Plotly widgets re-render
  slowly in headless Chromium: wait ~10 s after a filter change before reading
  values in a Playwright check (fast clicks are not lost, just delayed).
  bslib puts the sidebar below the content on phones; no `open=` option
  changes that.

- Panel prototype: `FastListTemplate`'s sidebar does not collapse on phones,
  so the filters sit in the main area. `panel serve` caches the script; restart
  the server after editing `app.py`. Panel content lives in shadow DOM: use
  Playwright locators (`get_by_text`), not `inner_text("body")`.

- Solara prototype: Solara 1.64 pulls ipyvuetify 3, whose `AppLayout` drawer
  overlays the content; pin `ipyvuetify<2`. `FigurePlotly` needs `anywidget`
  and never resizes charts (stuck at 700 px); an inline Vue template calls
  `Plotly.Plots.resize`. Theme colors only apply when set inside `Page`. An
  `AppLayout` inside `Page` renders "embedded"; use a module-level `Layout`.
  `assets/custom.js` is looked up in the parent folder of the app, not next to it.

- NiceGUI prototype: ECharts JS formatters need a leading `:` on the option key
  (`":formatter"`). Without `grid.containLabel` and `legend.type = "scroll"` the
  stacked chart's legend overlaps the axis. `fuser -k 8080/tcp` stops the server.
- Reflex prototype (0.10): theme goes into `rxconfig.py` via
  `rx.plugins.RadixThemesPlugin` (`App(theme=...)` is deprecated); disable
  `SitemapPlugin` to silence warnings. Radix layout props use `spacing="4"`,
  not `gap="4"` (that becomes invalid CSS). `rx.checkbox_group` has no change
  event. Recharts 3 sorts legend items by name (fix: `itemSorter` "() => 0").
  First `reflex run` takes ~1-2 min; `fuser -k 3000/tcp 8000/tcp` stops it.
  Reflex writes `reflex.lock/` (gitignored).
- Quarto prototype (1.10.19): an OJS declaration `x = ({a: 1, b: 2})` is
  silently dropped in dashboards (only "x is not defined" elsewhere); use the
  block form `x = { return {...} }`. Inline `${…}` in Markdown failed with
  string literals; precompute texts in the OJS cell. `ojs_define` output must not
  sit in an `include: false` cell, and any cell outside the sidebar/rows becomes
  an empty card, so the Python and setup cells live in the sidebar. With
  `scrolling: true` Plot charts grow endlessly (they take the card height);
  give them a fixed `height`. Hidden rows keep their grid track, so the hint
  lives in the Datenstand row. `fuser -k 4200/tcp` stops `quarto preview`.
- Evidence prototype: `npx degit evidence-dev/template` now gives an Evidence
  Studio project (hosted CLI, login); the open-source version is on the
  template's `legacy` branch. Needs `overrides.typescript ^5` (TS 7 peer
  conflict). Chain page queries with `${name}`, not `from name`. An empty
  multi-select `${inputs.x.value}` is a subquery, and DuckDB rejects alias
  reuse next to it: compute selection flags in a CTE. In dev the query
  viewers always show; `neverShowQueries` only hides them in the build.
  Read tool may show a stale image for an overwritten PNG path; copy first.
- React prototype: Vite serves `public/` as-is, so `copy_data.js` copies the
  CSVs there (`predev`/`prebuild`). `vite.config.js` uses `base: "./"` so
  `dist/` works from any path. Do not parse `meta.csv` with `d3-dsv` `autoType`
  (the ISO update date becomes a `Date`). Node Playwright is global:
  `require("$(npm root -g)/playwright")`.
- Session spawns can stall on a permission prompt ("Create S…") in auto mode;
  the fallback routine then restarts the chain after 0,5 h without commits.
- CLAUDE.md forbids AI-attribution lines in commits and PRs; it overrides the

- `_shared/.sqlfluff` sets `max_line_length = 100`; black is run with `-l 100`.
